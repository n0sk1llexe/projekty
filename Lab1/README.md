

\# Laboratorium 1 – Moje hobby



Projekt wykonany w ramach przedmiotu Programowanie internetowe.



\## Opis projektu

Strona internetowa poświęcona piłce nożnej, ze szczególnym

uwzględnieniem Lecha Poznań, Ekstraklasy oraz taktyki piłkarskiej.



Aplikacja posiada trzy podstrony:

\- Strona główna (/)

\- O hobby (/about/)

\- Galeria (/gallery/)



\## Technologie

\- Python

\- Django

\- HTML

\- CSS (Flexbox)



\## Uruchomienie projektu

1\. Zainstaluj wymagane biblioteki:

&#x20;  python -m pip install -r requirements.txt



2\. Przejdź do folderu moje\_hobby:

&#x20;  cd moje\_hobby



3\. Uruchom serwer:

&#x20;  python manage.py runserver



4\. Otwórz w przeglądarce:

&#x20;  http://127.0.0.1:8000/
